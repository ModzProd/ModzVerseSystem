The ModzVerse project has generated its first complete worker roster for RAIBARAZU — the flagship promotion. This is the biggest remaining BETA gap being addressed: the world's structural foundation (promotions, events, titles, venues, match gimmicks, TV networks) is now complete, and the human layer is beginning to take shape. The roster file is available as a downloadable SQL file in the repository's DLC/Rosters/ folder, ready to load into any ModzVerse save database.

⚠ Fictional Characters Disclaimer: All worker names and characters in this roster are entirely fictional. Any resemblance to real-world professional wrestlers — living or dead — is purely coincidental. The ring names, real names, biographies, and personality traits are original creations for the ModzVerse fictional world and do not represent or reference any actual person.

How to Load the Roster

Load the RAIBARAZU roster into your save database
$sqlite3 ModzVerse(BETA).db < DLC/Rosters/RAIBARAZU_roster.sql

# Or open in DB Browser for SQLite → Execute SQL tab → paste the file contents

The SQL file contains 30 INSERT INTO workers statements (149 columns each) and 30 INSERT INTO contracts statements. Worker IDs 1001–1030 are reserved and will not conflict with any existing workers (the main DB currently has 0 workers). After loading, the workers will appear in-game under RAIBARAZU, split between Doragon and Fenikkusu brands via the contracts.brandID field.

★ The Doragon-Fenikkusu Dream Match
The single most anticipated match in the ModzVerse is the Doragon ace versus the Fenikkusu ace — the main event of Battle of Rivals. With the roster now populated, the dream match is Ryūga the Apex (Doragon's #1 face, wrestling 95, star power 92) versus Yuya Ueno (Fenikkusu's #1 face, wrestling 84, star power 68).
