## How to Load the Roster

1. Open the `RAIBARAZU_roster.sql` file in a text editor
2. Execute it against your ModzVerse save database using any SQLite client:
   ```
   sqlite3 ModzVerse(BETA).db < RAIBARAZU_roster.sql
   ```
3. Or open the DB in DB Browser for SQLite and paste the SQL into the "Execute SQL" tab
4. The 30 workers and 30 contracts will be inserted, ready for the game to load

## Schema Notes

- Each worker INSERT populates all 149 columns of the `workers` table
- Each contract INSERT populates the `contracts` table with the worker's brand assignment
- All workers are: Male, Japanese, based in Tokyo, Pure Wrestling style, type=Wrestler
- Body conditions, stamina, and skill substats are derived from the worker's age and push tier
- Personality traits are randomly assigned with face/heel-appropriate probabilities
- Regional popularity is set to 0 for all continents except Asia (10-30 random) to match RAIBARAZU's regional profile
