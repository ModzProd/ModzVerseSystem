Repository Overview

The ModzVerse Intranet source code is hosted on GitHub at github.com/ModzProd/ModzVerseSystem. The repository contains the complete single-file HTML intranet, a README documenting the project, and a .gitignore file that excludes the source databases and analysis scripts (which are too large for the repo itself but available as release assets or in the source sandbox). The repository is public — anyone can view, fork, and clone it without authentication.

How to Get the Intranet

There are three ways to get a copy of the ModzVerse Intranet, depending on your needs:

Option 1: View Online (no installation)

The intranet is hosted live via GitHub Pages at https://modzprod.github.io/ModzVerseSystem/. Open the URL in any modern browser — the wiki loads instantly, no installation, no download. This is the recommended way to read the wiki for casual browsing.

GitHub Pages serves the index.html file directly from the main branch, with no build step required. Updates pushed to the repo go live within ~60 seconds.

Option 2: Download a Single File

If you want a local copy that works offline, download just the index.html file directly from the repository:

Direct download URL
→https://github.com/ModzProd/ModzVerseSystem/raw/main/index.html

Save it anywhere on your computer and double-click to open in any browser. The file is fully self-contained — no internet required after download.

Option 3: Clone the Repository (for contributors)

If you want to contribute to the project or track changes, clone the repository using git:

HTTPS clone (no GitHub account needed for read-only)
$git clone https://github.com/ModzProd/ModzVerseSystem.git
$cd ModzVerseSystem
$open index.html # macOS — use 'start index.html' on Windows, 'xdg-open index.html' on Linux
SSH clone (requires SSH key set up with GitHub)
$git clone git@github.com:ModzProd/ModzVerseSystem.git
GitHub CLI (requires gh installed)
$gh repo clone ModzProd/ModzVerseSystem

How to Contribute

The ModzVerse is a community world-building project — contributions are welcome. The standard GitHub fork-and-pull-request workflow applies:

Step 1

Fork the Repository

Click the "Fork" button at the top-right of the repository page. This creates a copy of the repo under your own GitHub account.

Step 2

Clone & Branch

Clone your fork locally, then create a feature branch: git checkout -b add-new-content. Never commit directly to main.

Step 3

Make Your Changes

Edit index.html (the entire intranet is one file). Test by opening it in a browser. Run git diff to review your changes.

Step 4

Commit & Push

Stage your changes (git add index.html), commit with a descriptive message, and push to your fork: git push origin add-new-content.

Step 5

Open a Pull Request

Go to your fork on GitHub and click "Compare & pull request". Describe your changes — a maintainer will review and merge.

Step 6

Go Live

Once merged into main, your changes go live on GitHub Pages within ~60 seconds at modzprod.github.io/ModzVerseSystem.

Issue Templates

When you open an issue at github.com/ModzProd/ModzVerseSystem/issues/new, you'll be prompted to choose an issue type. The repo supports five issue templates to streamline contribution:

Template Use For Required Fields
BUG Bug Report Reporting factual errors, broken links, typos, or rendering issues in the intranet Description, expected vs. actual behavior, browser, screenshot (optional)
FEAT Feature Request Proposing new sections, new venue packs, new UI features, or expanded content Use case, proposed solution, alternatives considered
CONTENT Content Contribution Submitting worker rosters, venue entries, match gimmicks, or angle templates Content type, promotion/event affected, attached file or inline data
DOCS Documentation Improvement Improving existing prose, fixing inaccuracies, expanding lore, translations Section affected, proposed change, justification
QUESTION Question / Discussion Asking about world-building decisions, seeking clarification, opening discussion Topic, context, what you've already checked

★ Community Vision
The ModzVerse was designed from the start as a community world-building project. The 6 promotions, the 13 signature events, the AEGIS LEAGUE championship, the 17 gimmicks, the 36,000 venues documented across 18 packs — these are the structural foundation. What brings the world to life is the human layer: workers with backstories, rivalries with history, venues with character. That layer is built by contributors. If you have an idea for a worker, a venue, a storyline, or a new angle template, open an issue and propose it. The world is yours to build.
