DLC: Match Gimmicks (75 databases · 1,334 match gimmicks)

The DLC/MatchGimmicks/ folder contains 75 filtered databases, each containing only the match gimmicks that fit a specific theme. The main ModzVerse database contains 1,334 match gimmicks total (IDs 1-1334); each DLC database extracts a subset of those gimmicks (and in some cases adds new ones) so a player can load only the match types they want without bloating their save file. All other tables (gimmicks, titles, promotions, workers, venues, etc.) remain intact in every DLC database.

★ Notable Match Gimmicks
The 1,334 match gimmicks include some genuinely creative concepts: a Piranha Pit Match (where the ring is surrounded by a piranha-filled pool), a Space Station Showdown, a Zombie Outbreak Match, a Witch's Coven Match, and a 5 Minute Sprint Match. The cultural packs are particularly thoughtful — the Lucha de Apuestas Mask vs Mask match is the lucha libre tradition's most dramatic stipulation, while the British Rounds Match preserves the old-world territorial wrestling format.

DLC: TV Networks (12 databases · 101 networks)

The DLC/TVNetworks/ folder contains 12 filtered databases, each containing all 78 tables from the main ModzVerse.db but with only a specific subset of the 101 total TV networks. Each DLC database includes the complete schema (databaseVersion=103) with all 15,303 gimmicks, 1,334 match gimmicks, 12,000 venues, 5,505 titles, and 5,000 promotions intact — only the networks and networkAvailability tables are filtered.

Notable Networks by Continent

Asia leads with 24 networks, including Japanese Wrestling Network (size 3, 5 regions), Puroresu TV (size 3, 5 regions), Tokyo Dome Network (size 2, 4 regions), and Bharat Wrestling TV (size 3, 5 regions) — covering both the Japanese and Indian wrestling markets. Europe follows with 21 networks led by British Wrestling Network (size 3, 4 regions) and the European Wrestling Alliance (size 3, 7 regions — the widest European coverage). North America has 18 networks led by WrestleNet USA, USA Sports Channel, and American Wrestling Network (all size 3, 5 regions).

South America has 19 networks (Brazil-led, with Canal Nacional, Sol Channel, Rio Channel, Luta TV Brasil, and Rede Luta Livre all at size 3) — a remarkably deep broadcast infrastructure for a continent with no home promotion in the launch roster. Africa has 10 networks (Nigeria, Egypt, and South Africa each have size-2 networks). Oceania rounds out the list with 9 networks, all Australian or New Zealand-based.

★ The Brazil Network Surprise
The TV Networks DLC reveals a second "Brazil surprise" to complement the venue pack finding: Brazil has 5 size-3 (Large) national TV networks — Canal Nacional, Sol Channel, Rio Channel, Luta TV Brasil, and Rede Luta Livre. This is the most size-3 networks of any single country in the ModzVerse. Combined with Brazil's 895 venues and 215 million population, this makes Brazil the single most strategically valuable untapped wrestling market in the world. A player starting a Brazilian promotion has broadcast infrastructure ready and waiting — no other untapped market comes close.

How to Use the DLC & Excel Resources

Loading a DLC Database

Each DLC database is a complete, self-contained SQLite file. To use one:

  1. Choose a DLC database that fits your booking theme (e.g., ModzVerse_MatchGimmicks_Cage.db for cage matches only)
  2. Download the .db file from the DLC folder on GitHub
  3. Replace (or merge) your existing Pro Wrestling Sim database with the DLC file
  4. Launch the game — all other tables (gimmicks, titles, promotions, workers, venues, etc.) remain intact; only the filtered table is changed

Using the Excel AI Prompts

The ModzVerse_All_Promotions_AI_Prompts.xlsx and ModzVerse_All_Venues_AI_Prompts.xlsx spreadsheets contain ready-to-use AI image generation prompts:

  1. Open the spreadsheet in Excel, Google Sheets, or LibreOffice Calc
  2. Find the promotion or venue you want to generate an image for (filter by continent, country, or style)
  3. Copy the contents of the "AI Logo Prompt (Improved)" or "AI Image Prompt (Improved)" column
  4. Paste into any AI image generator (Midjourney, DALL-E 3, Stable Diffusion, etc.) and generate
  5. The "Improved" column gives more reliable, more detailed results than the "Original" column
⚠ Schema Version Note
All 87 DLC databases are at schema version 103, while the main ModzVerse world is at schema version 121. When loading a DLC database into a v121 save file, PWS will run a migration to bring the schema up to v121 — this is automatic but may take a few seconds. Do not be alarmed if you see migration messages in the console.
