Print / Export

The ModzVerse Intranet includes a built-in print stylesheet that produces a clean, paginated document when you use your browser's print function. The print version hides all navigation, sidebar, search, and interactive elements, and reflows the content into a single-column, black-on-white layout suitable for printing on paper or exporting as a PDF.

How to Print or Export as PDF

Method 1: Button
Click the "🖨 Print / Export PDF" button on the Portal Dashboard. This will open your browser's print dialog.
Method 2: Keyboard shortcut
Press Ctrl+P (Windows/Linux) or Cmd+P (macOS) anywhere in the intranet.
Method 3: Browser menu
Use File → Print or File → Export as PDF in your browser's menu.

In the print dialog, choose "Save as PDF" as the destination to produce a PDF file. Choose your actual printer to produce a paper copy.

Print Recommendations

  • Paper size: A4 or Letter (the print stylesheet works with both)
  • Margins: Default (the print stylesheet does not set margins, so your browser's defaults apply — typically 0.4 inches / 1 cm on all sides)
  • Scale: 100% (do not scale down — the content is designed for full-width printing)
  • Background graphics: Off (the print stylesheet uses solid colors, not background images, so this setting does not matter — but turning it off produces a smaller PDF)
  • Headers and footers: Off (the intranet has its own footer; the browser's default headers/footers with page numbers and URLs are unnecessary)

What Gets Printed

The print stylesheet includes every section of the intranet — the portal, news, sitemap, wiki, promotions, events, titles, brands, gimmicks, geography, BETA status, and system pages. The print is comprehensive: it is the entire intranet, paginated for paper.

The print stylesheet excludes: the top navigation bar, the sidebar, the back-to-top button, the search box, the search results overlay, and the offline-ready badge. These are interactive elements that do not make sense on paper.

Page breaks are inserted before each <section> and <article> element via the page-break-after: always rule on the .section-divider class. This means each major section starts on a new page.

Estimated Print Size

Based on the current content inventory, a full print of the intranet will produce approximately 40–60 pages of A4/Letter content, depending on browser rendering. The largest sections are the six promotion profiles (each ~3-5 pages) and the events section (~4-5 pages).
