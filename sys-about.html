About this Intranet

The ModzVerse Intranet is a fully offline, single-file knowledge system for the ModzVerse pro wrestling world. It is designed to be the canonical reference for anyone working with the ModzVerse world database — players booking the world, modders extending it, or contributors documenting it. The intranet is built as a single self-contained HTML file: every page, every style, every script is embedded. No internet connection is required to read, search, navigate, or print any of the content.

How to Use This Intranet

The intranet is organized into four layers, each serving a different use case:

  • The Portal (this section's parent) is the dashboard landing page. Use it when you want a quick overview of the world's state or quick access to the six promotions.
  • The News Feed is the chronological log of changes. Use it when you want to know what has changed since the last time you opened the intranet.
  • The Wiki (Overview, Lore, Promotions, Events, Titles, Gimmicks, Geography) is the canonical reference. Use it when you need to look up a specific fact about a specific entity.
  • The System pages (Sitemap, About, Print) are the meta-layer. Use them when you need to navigate, understand, or export the intranet itself.

For searching: type into the search box at the top-right. A live results overlay will appear showing matching sections with snippets. Click any result to jump to that section.

For printing: click the "Print / Export PDF" button on the Portal dashboard, or use Ctrl+P / Cmd+P anywhere. The print stylesheet will hide the navigation and produce a clean, paginated document.

For sharing: the entire intranet is a single HTML file. Copy the file, email it, put it on a USB stick, host it on a web server — it works everywhere, with zero setup.

Source Material

The intranet's content is derived from two source files:

  • ModzVerse(BETA).db — the SQLite world database (12 MB, 93 tables, schema version 121). This file contains the canonical data: promotions, events, titles, brands, gimmicks, countries, regions, game balance, and the empty tables that represent the BETA gaps.
  • The PWS codebase (main.html + PWSFilesJS/*.js, ~111k LOC across 96 files) — the Pro Wrestling Sim renderer source code. The codebase defines the schema, the simulation rules, and the meaning of every database field. Without the codebase, the database is just rows of numbers; the codebase gives those numbers meaning.

All in-universe lore in this intranet is written to be consistent with the database fields. Where the database is silent (e.g., worker histories, since the roster is empty), the lore is explicitly speculative and marked as such.
